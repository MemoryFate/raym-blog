## 技术架构

### 前端框架
- **Vue 3** - 渐进式 JavaScript 框架，使用 Composition API (`<script setup>`)
- **Vue Router 4** - Hash 模式路由，支持懒加载
- **Ant Design Vue 4** - UI 组件库

### 构建工具
- **Vite 5** - 下一代前端构建工具
  - 路径别名: `@` → `src/`
  - Vue 插件支持
  - 开发服务器 `--host` 模式

### 业务模块

| 模块 | 技术实现 |
|------|----------|
| 迷宫游戏 | Canvas 2D 绘制 + DFS/A* 寻路算法 |
| 数独游戏 | 回溯算法生成/求解，html2canvas 导出 |
| 二维码生成 | qrcode 库，Canvas 渲染，支持图标嵌入 |
| 字符串生成 | Web Crypto API (crypto.getRandomValues) |
| AES-GCM | node-forge 库，加密结果 Base64 编码 |
| WebSocket Demo | ws 库，服务端与客户端分离 |

### 状态管理
- 当前项目**未使用** Pinia/Vuex
- 组件内使用 `reactive()` / `ref()` 管理本地状态
- WebSocket 连接使用组件内 `const ws = new WebSocket(...)`

### 数据流

```
用户操作 → 组件事件 → 修改 reactive/ref 状态 → Vue 响应式更新视图
```

### WebSocket 架构

```
SocketDemo.vue (服务端)          SocketClientDemo.vue (客户端)
      │                                    │
      │ ←─────── ws://192.168.0.104:2334 ──┤
      │                                    │
      └──────── 广播消息给所有客户端 ───────┘
```

服务端独立运行 (`node src/js/server.js`)，不通过 Vite 开发服务器。
